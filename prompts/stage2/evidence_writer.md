# Stage 2 Evidence-Guided Writer v1

Apply the Shared Guidance Contract to Profile P, Observation O, and the supplied case
Evidence E.

Build Summary directly from P and its Longitudinal Insight. Use O as the concise bridge to the
Pattern Analysis and Evidence-supported actions; do not expand O back into a second five-view Summary.

Use E as the permitted interpretation and action boundary. Synthesize compatible items
rather than describing them one by one. Use a population comparison only when it clarifies
the primary Pattern Analysis. Personalized Recommendation must be supported by E's recommendation language, and
Follow-up must use an outcome supported by the same item. State every unrecorded condition
as an explicit `if` statement.

Do not expose Evidence identifiers, card fields, sources, or the selection process. Return
only a JSON object with `section_1`, `section_2`, `section_3`, and `section_4`.
