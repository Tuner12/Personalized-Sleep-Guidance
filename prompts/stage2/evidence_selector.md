# Stage 2 Evidence Selection Task v2

Use Profile P, concise Observation O, and the complete generation Evidence bank to produce the
smallest coherent case Evidence set E.

Begin with O's `primary_observation`. Use supporting and context observations only when they
materially change interpretation, action, or a necessary boundary. Select only items that
connect the observed pattern to a coherent Pattern Analysis, Personalized Recommendation, and Follow-up. The set
must include action support: direct guidance, specific maintenance, one justified conditional
action, or a justified professional-care boundary.

Do not select a population comparison merely because a value crosses it. Do not infer an
unrecorded exposure. At most one unrecorded condition may be selected, and it must address the
primary observation more specifically than available alternatives. Do not choose among
interchangeable caffeine, alcohol, noise, or environmental factors merely for variety.

For each selected item, copy its supplied card semantics exactly, add one natural
`case_relevance` sentence linking O to the item, and retain only outcome metrics supported by
both the case and the card. The selection summary should connect the primary observation to the
minimal interpretation and action support without mentioning retrieval, routing, cards, or
what the Writer should do. Return only the target E JSON structure.
